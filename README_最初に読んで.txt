# アメリカボウル対策問題集 — 画像修正・PWA版

## 修正内容

- Wikimedia の旧 `upload.wikimedia.org/.../400px-...` 画像URLを、新しい `thumb.wikimedia.org` の標準サイズURLへ変更。
- 画像を最初からリモートURLで表示し、必要な場合だけローカル画像へフォールバック。
- ブラウザが `navigator.onLine` を誤判定しても、画像表示や手動キャッシュを止めないよう修正。
- Service Worker のキャッシュ名を `benkyo-v3` に更新し、新しい画像ドメインもキャッシュ。
- PWA manifest、アイコン、Service Worker、アプリのインストールボタンを同梱。

## GitHubへ反映する方法（コード編集不要）

1. ZIPをダウンロードして、端末上で解凍します。
2. GitHubの `america-bowl/benkyo` リポジトリを開きます。
3. `Add file` → `Upload files` を選びます。
4. 解凍したフォルダの**中身**（`index.html`、`sw.js`、`manifest.webmanifest`、`portraits.json`、`icons` フォルダなど）をアップロード欄へ入れます。フォルダ名 `benkyo` 自体ではなく、その中のファイルとフォルダをアップロードしてください。
5. 同名ファイルは上書きされます。下部の `Commit changes` で保存します。
6. Vercelでデプロイが完了したら `https://americabowl.vercel.app/` をオンラインで開き、強制再読み込みします（Windows/Chromebook: `Ctrl` + `Shift` + `R`）。

## 画像とオフライン保存

- オンラインで開くと肖像画が読み込まれ、Service Workerが読み込んだ画像をキャッシュします。
- `肖像画をオフライン保存` を押すと、一覧の71枚を一括保存します。表示が `オフライン保存完了 71/71枚` になれば完了です。
- すべてのカードを初めてキャッシュする時はオンライン接続が必要です。
- ブラウザのサイトデータを消去すると画像キャッシュも消えます。

## PWAとしてインストール

- 対応ブラウザでインストール可能な場合は、ページ内の `アプリとしてインストール` ボタンが表示されます。
- ボタンが表示されない場合、Chromeの右上 `⋮` メニューから `アプリをインストール` / `ページをアプリとしてインストール` を探してください（表記はブラウザのバージョンにより異なることがあります）。
- インストール後はアプリのような独立ウィンドウで開けます。オフライン起動には、最初にオンラインで開いてページを保存しておく必要があります。

## 注意

このZIPにはJPG画像そのものは含めていません。オンライン表示とService Workerによるブラウザ内キャッシュを使います。オフライン保存済みの画像はその端末・ブラウザ内に保持されます。
