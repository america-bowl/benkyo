# アメリカボウル対策サイト：肖像画・オフライン対応

このフォルダーは `america-bowl/benkyo` のルートに配置する、Vercel/GitHub用の更新一式です。

## 含まれるもの

- `index.html` — 対策問題集。大統領45人＋人物26人の肖像画、拡大表示、出典リンクを追加。
- `sw.js` — サイト本体と肖像画のキャッシュを管理する Service Worker。
- `portraits.json` — 71点の肖像画URL、人物名、ファイル名、Commons出典。
- `manifest.webmanifest` / `icons/` — ホーム画面に追加できるWebアプリ情報とアイコン。
- `CREDITS.md` — 各肖像画の出典・ライセンス確認リンク。
- `scripts/download_portraits.py` — 希望する場合、71枚を `images/` に取得して同一サイトから配信する補助スクリプト。

## GitHub と Vercel への反映

1. ZIPを展開します。
2. 中身をリポジトリ `america-bowl/benkyo` のルートへコピーし、同名の `index.html` と `sw.js` を置き換えます。
3. GitHub に commit/push します。Vercelがそのリポジトリを追跡していれば、自動で再デプロイされます。
4. `https://americabowl.vercel.app/` を HTTPS で開きます。初回表示後、肖像画欄の保存状況が「オフライン保存完了 71/71枚」になるまでオンラインのまま待ちます。必要なら「肖像画をオフライン保存」を押します。
5. 保存後にサイトを再読み込みし、機内モードなどで表示を確認します。

## 画像をリポジトリ内に保存したい場合（任意）

ZIPを展開したルートで `python3 scripts/download_portraits.py` を実行すると、肖像画を `images/` に保存できます。その後 `images/` も含めて GitHub に push すれば、画像を同一サイトから配信できます。ZIPには元画像ファイル自体は含まれません。実行時にネット接続が必要です。画像が `images/` にない場合も、サイトはオンラインで Wikimedia の画像を表示し、Service Worker が初回アクセス時にキャッシュします。

## オフライン利用の条件

- Service Worker は HTTPS（Vercel）か localhost でのみ動作します。`file://` で直接開いたHTMLではオフラインキャッシュは動作しません。
- 初回のオンライン表示と肖像画の保存完了が必要です。ブラウザのサイトデータを消去するとキャッシュも消えます。
- ブラウザ・端末の容量制限や省データ設定により、全画像を保存できない場合があります。その場合はオンラインで再試行してください。
- Google Fonts はネット接続時のみ取得します。オフライン時は端末の日本語フォントへフォールバックします。

## 変更後の反映で気をつけること

Service Workerはバージョン更新により古いキャッシュを入れ替えます。デプロイ後すぐに見た目が変わらない場合は、ページを一度再読み込みし、ブラウザのサイトデータを更新してください。

## 安全に反映する

この更新用一式を作成してありますが、こちらからGitHubへログイン・commitしたり、Vercelのデプロイを実行したりはしていません。GitHubのパスワード、Personal Access Token、Vercelトークンは共有しないでください。ご自身のGitHubでファイルを置き換えてcommitする方法が安全です。
